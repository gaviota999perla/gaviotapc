## Si quieres variarlas

Estas imágenes se generaron con una plantilla propia (no Canva), así que para cambiar la foto, el texto o hacer una versión nueva para otro evento, solo dímelo — genero una nueva versión con la foto o el texto que quieras y te la mando lista igual que estas.

Nota: las plantillas equivalentes en Canva (`../disenos/README.md`) se mantienen como respaldo/editable, pero estas imágenes de aquí son la versión final recomendada para publicar.
