# Prompts para generar imágenes con IA

Úsalos en cualquier generador de imágenes (Bing Image Creator/Designer, ChatGPT/DALL·E, Midjourney, Canva IA, Ideogram, etc.). Cópialos tal cual o ajusta el detalle del evento (nombre, colores). Cuando tengas las imágenes generadas, súbelas aquí al chat y te las dejo listas (texto, logo y ajustes de contraste) igual que las 8 actuales.

## Estilo base (pégalo al inicio de cualquier prompt para mantener consistencia de marca)

```
Fotografía profesional de un salón de eventos de lujo tipo quinta/finca en Ecuador,
estilo elegante y aspiracional, iluminación cálida dorada, paleta negro y dorado,
jardines tropicales, piscina, decoración floral elegante, ambiente romántico y sofisticado,
alta resolución, fotografía de marketing/publicidad para redes sociales, sin texto ni logos.
```

## Prompt — XV años

```
[Estilo base] + Decoración de quinceañera elegante junto a una piscina al aire libre,
arco floral circular con flores rosas y blancas, mesa de torta de varios pisos,
luces cálidas, ambiente de fiesta sofisticada al atardecer, sin personas visibles,
formato vertical 4:5.
```

## Prompt — Bodas

```
[Estilo base] + Arco de ceremonia de boda decorado con flores blancas y rosas en un
jardín tropical, cortinas blancas, sillas doradas en filas, atardecer romántico,
piscina de fondo, ningún invitado visible, formato vertical 4:5.
```

## Prompt — Cumpleaños

```
[Estilo base] + Mesa de dulces y postres decorada con flores y globos elegantes en tonos
dorado y rosa, ambiente festivo pero sofisticado, jardín con piscina de fondo,
luz de día, sin personas visibles, formato vertical 4:5.
```

## Prompt — Corporativo

```
[Estilo base] + Vista amplia de una piscina y jardines con carpas blancas montadas para
un evento empresarial, mesas y sillas elegantes, ambiente profesional pero natural,
luz de día despejada, sin personas visibles, formato vertical 4:5.
```

## Para formato Historia/TikTok (vertical 9:16)

Agrega al final de cualquiera de los prompts de arriba: `, formato vertical 9:16, encuadre alto mostrando más del entorno`.

## Notas

- Pide siempre **"sin texto"** y **"sin logos"** en el prompt — el texto y el logo de Quinta La Dorada se los agrego yo después, a mano, para que queden bien puestos y legibles.
- Si el generador no entiende bien en español, tradúcelo al inglés (por ejemplo con el mismo Bing/ChatGPT) y pégalo igual.
- Cuantas más imágenes variadas tengamos (bautizos, aniversarios, fin de año), más fácil es seguir el calendario sin repetir siempre las mismas 8.
